**GAPO 0.9 beta** is the first release of GAPO for real Steam games. It measures your games while you play, tells you what limits them, and, only when you ask, tests one game setting at a time and keeps only what measurably helps.

> This is a beta. GAPO has been tested end to end on its own test games, on a Windows 10 laptop and on Windows CI, but not yet on commercial Steam games. Please report what you see.

### Install

1. Download `GAPO-0.9.0-win-x64.zip` below and unzip it.
2. Double-click **Install.cmd**. No administrator rights are needed.
3. Say **Y** when it offers to add your account to *Performance Log Users*, then sign out and in once. GAPO can then read frame times without running as administrator.

Requires Windows 10 or 11, 64-bit. Not code-signed yet: SmartScreen may ask you to confirm (**More info → Run anyway**). `READ-ME-FIRST.md` in the zip is the full guide.

### What it does

- **Any Steam game:** live FPS, frame time, stutters, processor load, and what limits the game.
- **Unreal Engine games without anti-cheat:** optimisation by game restart, one setting at a time.
- **Games with Easy Anti-Cheat or BattlEye:** measured only, never touched.
- **Optimise shows a plan first:** the settings to test, the restarts needed and an estimated time. Nothing changes until you press **Start**. A progress bar shows the time left.
- **Full control:** lock settings, set values yourself, put back single settings, ask before each change, forbid frame-rate caps, choose a frame-rate target, limit restarts, or switch the optimiser off.
- **FPS overlay:** live FPS, plus before and after once a game has been optimised. It is a separate window, never injected into the game.
- **Revert all** restores every original setting; the uninstaller offers to do it too.
- **No injection:** GAPO never injects into games, reads game memory, installs drivers or closes programs.

### Known limits

- Only Steam libraries are searched.
- Only Unreal Engine games can be optimised so far.
- GPU busy time is missing with hardware-accelerated GPU scheduling.
- Measuring without administrator rights through *Performance Log Users* is new and has not yet been verified on a beta PC.

Verify the download: the SHA-256 checksum is in `GAPO-0.9.0-win-x64.zip.sha256`.
